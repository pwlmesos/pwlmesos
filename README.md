## Selected projects

- **[CairnLodge](https://github.com/codadensys/cairnlodge)**  
  Customer-scoped container CVE and SBOM tracking: digest-backed snapshots, scanner normalization (Trivy, Grype, CSV), lineage and reduction metrics, RBAC, OIDC.
  - **Stack**: Go, React + TypeScript, Postgres / CockroachDB, Docker, Prometheus/Grafana
  - **Highlights**: Hardened container runtime, multi-tenant data isolation, archive/restore and mutable-tag drift detection

- **K8s Node Builder** (GitLab: [codadensys/k8s-node-builder](https://gitlab.com/codadensys/k8s-node-builder))  
  Kubernetes node image pipelines with Packer and CI/CD for EKS-style node AMIs.
  - **Stack**: Packer, AWS (Amazon Linux 2023), GitLab CI, Docker
  - **Highlights**: Reproducible node images, image-build pipelines

- **Examples**  
  Public code samples and snippets for articles and reference.

- **Images**  
  Image build and CI/CD pipeline definitions for container and AMI builds.
